# Valta — варианты блоков

GitHub Pages открывает `index.html`. Для локального просмотра откройте `preview.html` в браузере. `page.html` — фрагмент для встраивания.
Все изображения находятся в `assets/`. Для сборки нужен Node.js, зависимостей нет.

```sh
./build.sh
```

## Восстановление исключённых вариантов

Из сборки исключены H3 «Парящий продукт», H4 «Горизонт», B4 «Процесс как график»,
C5 «3D-колода» и A5 «Терминал». Их исходники, стили и изображения сохранены.
Исключённые варианты не попадают в HTML и навигацию, их скрипты не запускаются.

Чтобы вернуть конкретный вариант, удалите его ID из `excluded-variants.json`
и запустите `./build.sh`. Чтобы вернуть все пять, замените содержимое файла на
`[]` и пересоберите. Исходные метки оставлены без перенумерации.
